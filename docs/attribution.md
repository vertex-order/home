# The `by` line

> **Guidance, not a hard rule.** These are judgment calls, not a spec.
> An AI editing this repo should follow them as the default and not
> deviate without a human explicitly saying so in the prompt — but if it
> thinks a case warrants breaking from them, it should ask the human
> first rather than either blindly applying the rule or silently
> deviating.

## Purpose

- `by` is a scannable ID hint, not a credits list or historical record.
- Job: let a fan glancing down the list go "oh, that one!" for a title
  that isn't self-explanatory (`Mana`, `Ogre`, `Tales of`).
- One name. Essentially never two. Never a sentence.

## Two rules that override everything else

- **Accuracy first.** `by` must be true of the *whole* entry. If an
  entry spans unrelated sources, only pick a name true of all of it, or
  split the entry.
- **Omit rather than mislead.** No good short answer exists → leave
  `by` blank. Blank beats a bad or misleading name.

## Books: always the author

Singular, uncontroversial, no further rule needed.

## Games / Movies & TV: fallback tiers, stop at first fit

1. **Iconic individual** — only if a fan would think "yes, that's whose
   series this is." Famous-for-something-else or famous-but-only-the
   -early-entries fails this, even for a household name.
   - ✅ Metal Gear → **Hideo Kojima** (directed nearly every entry).
   - ❌ Kirby ≠ Sakurai (left the studio in 2003, mostly known for
     *Smash Bros.* now) → falls to tier 2.
2. **Originating studio** that defined the franchise's DNA, even after
   later entries moved to a different developer.
   - Kirby → **HAL Laboratory**. Tomb Raider → **Core Design**.
     Deus Ex → **Ion Storm**.
3. **Publisher/IP-holder brand** — only if the brand itself is a
   recognizable identity, not a generic mega-distributor.
   - Star Wars (games) → **Lucasfilm**. ❌ never "Universal Pictures"
     for anything — tells a fan nothing.

## Cross-medium notes

- Same title, different list → `by` can differ per list (describes who
  made *that* version).
  - Star Wars (Screen) → **George Lucas** (wrote/directed the bulk of
    the original-era films; tier 1 passes here, unlike Kirby).
  - Star Wars (Games) → **Lucasfilm** (he made no games).
- Unambiguous titles (Star Wars, MCU) — `by` barely does identifying
  work regardless. Don't over-invest in these.

## Worked example: `Alien / Predator`

- Two unrelated IPs merged into one entry for the crossover titles.
- No name is true of both halves → `by` omitted entirely.
- A technically-accurate distributor name would be uninformative; a
  director's name would be flatly wrong for half the entry. Blank wins.
